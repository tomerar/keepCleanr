# G1b: guarded MediaStore PNG read (in progress)

This internal increment builds on PR #69. It re-observes a scanner-provided MediaStore row around a bounded PNG decode, checks the read byte count against the observed size and withholds features on scope or source-version changes. The required callback must enforce the current run, permission epoch, selected scope, kept choices and exclusions. There is no application caller or real permission-epoch coordinator. An observation or perceptual hash is never a backup proof, safety-category change or disposal authority.

Local `:core:gallery-android:testDebugUnitTest :testing:architecture:test spotlessCheck` passed on the stacked parent: seven guarded-read tests, seven MediaStore observation tests, six PNG decoder tests and seven canonical-pixel tests, plus architecture and formatting. The guarded tests use a fake MediaStore and injected stream to cover current read, no-open for rejected scope, source replacement, permission-scope reduction, length mismatch, access failure, stream closure and cancellation. `:core:gallery-android:assembleDebugAndroidTest` also passed for the actual MediaStore/PNG instrumented test; execution on Android 30/36 is pending CI. These are synthetic correctness fixtures, not photographic accuracy or physical-device results.

This is not complete G1b: permission epoch/selected-photo authority, post-observation races at publication and action boundaries, blocked-provider cancellation, full source formats, cache/migration/quota and actual app wiring are pending. Current-head CI/review and parent PR #69 must pass before merge. No photos are selected or deleted.
