# Gallery evaluation tooling: preparatory checkpoint

Date: 2026-11-08. This small developer-only tool is independent preparation for G2. It neither advances nor passes G2, and it does not bypass the G1a → G1b → G2 milestone dependencies. No app code or personal image data is involved.

`scripts/gallery-benchmark-score.py` reads labelled opaque identifiers and processing states from local CSV files, validates event/split and bootstrap-cluster isolation, and produces aggregate JSON. It scores every suggested group pair, counts false-merge groups and unlabelled/ambiguous cases, includes unprocessed labelled matches in the recall denominator, reports optional pre-reranking candidate recall, and computes a bounded deterministic cluster-bootstrap interval for known suggestions. It reports coverage and sample strata without asserting an acceptance-gate pass. See [the benchmark protocol](../spec/gallery-benchmarks.md#offline-scoring-tool--preparation-for-g2) for input schemas, constraints and limitations.

Verification performed: `python3 -I -B -m unittest discover -s scripts/tests -p 'test_gallery_benchmark*.py' -v` passed 15 synthetic tests; `git diff --check` passed. Tests cover missed and unprocessed matches, false merges, unknown/ambiguous labels, overlapping and oversized groups, event/digest split leakage, correlated event and identical-content clusters, reproducible and bounded resampling, missing inputs, and aggregate-only output. CI invokes the same tests. Synthetic tests are evidence of scoring behavior, not of photographic quality.

Still required: G1a's PR gate, the G1b Android adapter/cache milestone, a licensed or consented real-image corpus with independent labelled families, frozen held-out data and thresholds, real-device latency/memory/energy studies, privacy review of any aggregate report, and all AC-G4/G2 gates. No AI decision or runtime is admitted by this tool. No image files or datasets were read or copied in developing it.
